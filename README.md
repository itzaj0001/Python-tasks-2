# Python-tasks-2

This repository contains two simple Python programs.

## Task 1: Even or Odd Number Checker
This program takes a number from the user and checks whether it is even or odd.

Example:
Enter a number: 7
7 is an odd number.

## Task 2: Sum of Numbers from 1 to 50
This program calculates the sum of numbers from 1 to 50 using a for loop.

Output:
The sum of numbers from 1 to 50 is: 1275
